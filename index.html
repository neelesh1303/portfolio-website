02 / GATEWAY & VECTOR CACHE ~4ms Latency • $0 Token Cost

LLM Cost & Latency Optimizer Gateway

High-throughput API proxy gateway built with Python and FastAPI that dramatically curbs inference expenses and latency by serving semantically identical prompts from memory and intelligently routing queries.

  • Dense Semantic Caching: Converts incoming queries into 384-dimensional dense vectors using Sentence-Transformers (all-MiniLM-L6-v2) and computes NumPy cosine similarity. Prompts exceeding a 0.85 threshold return in ~4ms at $0 cost.
